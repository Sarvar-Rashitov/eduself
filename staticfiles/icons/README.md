## Icon yaratish uchun:

### Avtomatik yaratish (Tavsiya etiladi):
1. https://realfavicongenerator.net/ saytiga kiring
2. Logo rasmingizni yuklang (kamida 512x512 px)
3. iOS va PWA sozlamalarini tanlang
4. Barcha kerakli o'lchamdagi iconlarni yuklab oling
5. Bu papkaga joylashtiring

### Boshqa tool'lar:
- https://www.pwabuilder.com/imageGenerator
- https://favicon.io/
- https://app-manifest.firebaseapp.com/

### Splash Screen yaratish:
- https://appsco.pe/developer/splash-screens
- https://progressier.com/pwa-icons-and-ios-splash-screen-generator

## Muhim eslatmalar:
- iOS Safari PWA qo'llab-quvvatlashi uchun barcha Apple Touch Icon'lar kerak
- Splash screen'lar iOS'da PWA ochilganda ko'rsatiladi
- Icon'lar PNG formatida bo'lishi kerak
- Shaffof fon tavsiya etiladi
